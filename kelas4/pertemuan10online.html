Pengertian cara kerja komputer

Komputer bekerja melalui empat tahapan: Input, Storage, Processing, dan Output.

TahapanArtinya
InputMemasukkan data atau perintah ke komputer.
StorageMenyimpan data agar bisa digunakan kapan saja.
ProcessingMengolah data menjadi informasi yang berguna.
OutputMenampilkan hasil olahan data.

Input

Perangkat: Keyboard, Mouse, Microphone.

PerangkatFungsiCara kerja
KeyboardMemasukkan teks atau perintah (misalnya, mengetik nama).Menekan tombol mengirim sinyal ke komputer untuk ditampilkan sebagai teks.
MouseMengklik atau memilih perintah di layar (misalnya, membuka aplikasi).Gerakan dan klik diterjemahkan menjadi perintah di layar.
MicrophoneMemasukkan suara (misalnya, rekaman suara).Suara diubah menjadi data digital oleh komputer.

Storage

Perangkat: Hard Disk Drive (HDD), Solid State Drive (SSD), USB Flash Drive.

PerangkatFungsiCara kerja
HDDMenyimpan data besar seperti dokumen dan foto secara permanen.Data disimpan di piringan magnetik yang berputar.
SSDMenyimpan data lebih cepat dari HDD.Data disimpan di chip memori tanpa bagian bergerak.
USB Flash DriveMenyimpan dan memindahkan data antar perangkat.Data disimpan di memori flash, mudah dibawa.

Processing

Perangkat: Central Processing Unit (CPU), Random Access Memory (RAM).

PerangkatFungsiCara kerja
CPUMengolah data seperti otak komputer (misalnya, menghitung atau menjalankan program).Menerima perintah, melakukan perhitungan, dan mengirim hasil.
RAMMenyimpan data sementara untuk mempercepat pemrosesan.Menyimpan data yang sedang digunakan, hilang saat komputer dimatikan.

Output

Perangkat: Monitor, Speaker, Printer.

PerangkatFungsiCara kerja
MonitorMenampilkan teks atau gambar (misalnya, dokumen atau video).Menampilkan data digital sebagai gambar di layar.
SpeakerMengeluarkan suara (misalnya, lagu atau suara video).Mengubah data digital menjadi suara.
PrinterMencetak data ke kertas (misalnya, dokumen tugas).Mengubah data digital menjadi cetakan fisik.

Contoh dalam kehidupan

Mengetik dan mengedit

Mengetik nama di keyboard (input), menyimpannya di USB (storage), mengeditnya di Word (processing), lalu menampilkannya di monitor (output).

Merekam lagu

Merekam suara lagu (input), menyimpannya di SSD (storage), mengolahnya di aplikasi (processing), dan memutarnya di speaker (output).
