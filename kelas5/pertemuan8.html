Petualang Gambar Digital

Jalan-jalan keliling sekolah, temui 20 teman, dan bantu mereka memahami gambar digital. Setiap teman punya satu soal. Pilih semua jawaban yang benar!

Pengertian gambar digital

Gambar digital adalah gambar yang dibuat atau disimpan dalam bentuk file di komputer.

Cara membuatnya

  • Bisa dibuat dengan aplikasi khusus.
  • Bisa diedit dari foto asli.

Contoh dan kegunaan

Contohnya
  • Gambar ilustrasi
  • Logo
  • Foto yang diubah
Digunakan untuk
  • Presentasi
  • Tugas
  • Seni digital

Format gambar digital

JPG

  • Cocok untuk foto.
  • Ukuran file kecil.
  • Kualitas sedikit berkurang.

PNG

  • Bagus untuk gambar dengan transparansi.
  • Ukuran file lebih besar.

GIF

  • Digunakan untuk animasi sederhana.
  • Ukuran file kecil.

BMP

  • Format lama.
  • Ukuran file besar.
  • Kualitas tinggi.
